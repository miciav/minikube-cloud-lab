SLIDE 38: Exercise 8: update and roll back hello-go
kubectl patch deployment hello-go --type=merge \
  -p '{"spec":{"minReadySeconds":20,"strategy":{"type":"RollingUpdate","rollingUpdate":{"maxSurge":1,"maxUnavailable":0}}}}'
In a second configured terminal, watch the Pods before starting the update:
kubectl get pods -l app=hello-go -o wide -w
Back in the first terminal:
kubectl set image deployment/hello-go hello-go=miciav/hello-go:1.1.0
kubectl rollout status deployment/hello-go --timeout=5m
kubectl rollout history deployment/hello-go
kubectl get pods -l app=hello-go -o wide
kubectl rollout undo deployment/hello-go
kubectl rollout status deployment/hello-go --timeout=5m
kubectl delete service hello-go
kubectl delete deployment hello-go
